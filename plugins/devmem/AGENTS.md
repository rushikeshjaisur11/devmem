## devmem
If the repo has `.devmem/index.json`, use the `devmem` skill for every coding task: `devmem recall "<task>"` first, `devmem find/show/impact` instead of reading whole files, `devmem diffcheck` before each commit, `devmem report` before the PR. If the `devmem` command is missing, run the install steps in the skill; if the repo has no `.devmem/`, work normally.
